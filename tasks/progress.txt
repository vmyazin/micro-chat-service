## Codebase Patterns
- Types in packages/shared/src/types.ts are auto-exported via `export * from './types'` in index.ts
- Use branded types (e.g., `UserId`, `GroupId`) from shared package for type-safe IDs
- Cross-package imports require `composite: true` in tsconfig and project references to the dependency package
