## Codebase Patterns
- Types in packages/shared/src/types.ts are auto-exported via `export * from './types'` in index.ts
- Use branded types (e.g., `UserId`, `GroupId`) from shared package for type-safe IDs
- Cross-package imports require `composite: true` in tsconfig and project references to the dependency package
- Use vitest for testing with config to exclude dist/ directory
- Add `@types/node` and `types: ["node"]` in tsconfig for Node.js globals like console
- D1/SQLite uses TEXT for dates (ISO format) and INTEGER for booleans (0/1)
- Use snake_case for database column names, but TypeScript interfaces use snake_case to match SQL
- Server package uses `types: ["@cloudflare/workers-types"]` in tsconfig for globals (crypto, TextEncoder)
- Hono router composition: `app.route('', childRouter)` mounts child router at app root
